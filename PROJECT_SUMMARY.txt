/**
 * ============================================
 * KINGSHOT COMBAT CALCULATOR BOT
 * ============================================
 * 
 * 📊 RESUMEN EJECUTIVO
 * 
 * Un bot de Discord completo para analizar combates en el juego
 * móvil Kingshot con extracción automática de datos via OCR.
 * 
 * ============================================
 * 🎯 FUNCIONALIDADES
 * ============================================
 * 
 * 1. COMANDO PRINCIPAL: /calculate [tropas_totales]
 *    - Usuario introduce sus tropas disponibles (ej: 900450)
 *    - Bot solicita screenshot del reporte de batalla
 *    - Bot extrae automáticamente stats via OCR
 *    - Bot analiza y recomienda composición óptima
 * 
 * 2. ANÁLISIS AUTOMÁTICO
 *    - Identifica estadísticas de tropas aliadas (izquierda)
 *    - Identifica estadísticas de tropas enemigas (derecha)
 *    - Extrae Ataque, Defensa, Letalidad, Salud de cada tipo
 *    - Calcula formación óptima
 * 
 * 3. SIMULADOR DE COMBATE
 *    - Simula batallas turno por turno
 *    - Usa fórmula exacta de Kingshot
 *    - Calcula bajas, daño, supervivientes
 *    - Determina victoria/derrota
 * 
 * 4. MÚLTIPLES COMBATES
 *    - Calcula si es necesario atacar varias veces
 *    - Estima cuántos combates se necesitan
 * 
 * ============================================
 * 💻 TECNOLOGÍA
 * ============================================
 * 
 * Frontend: Discord (Slash commands, Embeds)
 * Backend: Python 3.10+
 * OCR: Tesseract + OpenCV + Pillow
 * Bot Framework: discord.py 2.3.2
 * 
 * ============================================
 * 🚀 INSTALACIÓN RÁPIDA (RASPBERRY PI 5)
 * ============================================
 * 
 * ssh knycat@192.168.1.141
 * 
 * git clone <repo> kingshot-bot
 * cd kingshot-bot
 * chmod +x install_rpi.sh
 * ./install_rpi.sh
 * 
 * # Luego, como servicio 24/7:
 * sudo cp kingshot-bot.service /etc/systemd/system/
 * sudo systemctl daemon-reload
 * sudo systemctl enable kingshot-bot
 * sudo systemctl start kingshot-bot
 * 
 * ============================================
 * 📱 FLUJO DE USUARIO
 * ============================================
 * 
 * 1. Usuario: /calculate 900450
 * 2. Bot: "Sube un screenshot..."
 * 3. Usuario: [Carga imagen]
 * 4. Bot: [Extrae stats via OCR]
 * 5. Bot: [Calcula y recomienda]
 * 6. Bot: Respuesta con análisis completo
 *

 * ============================================

 * ✅ Fórmula de daño: √Tropas × (Ataque × Letalidad) / (Defensa × Salud) × SkillMod
 * ✅ Orden de ataque: Infantry → Cavalry → Archers
 * ✅ Sistema de contrapesos: Inf > Cav > Arc > Inf
 * ✅ Simulación turno a turno
 * ✅ Cálculo de bajas precisas

 * ✅ Predictor de multiple-combates
